Como publicar este projeto no GitHub Pages:

  1. Crie um repositório no GitHub (ex: meu-emagrecimento).
  2. Faça upload deste arquivo com o nome exato de index.html no repositório.
  3. Vá em Settings > Pages e selecione a branch main (ou master) / root.
  4. Acesse o link gerado pelo GitHub Pages para ver seu app online no celular e computador!
